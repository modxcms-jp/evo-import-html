# Import HTML

Evolution CMS JP Edition 用の、HTML ファイルで作られたサイトを文書としてまとめて取り込むモジュールです。

もとは本体の管理画面の「ツール → インポート」（HTMLからサイトをインポート）でした。本体から外し、使い続けたいサイトのためにモジュールとして独立させています。

## 本体から外した理由

- **誤操作でサイトを失いやすい**: 「文書ツリーを空にする」を選ぶと、ごみ箱を通さずにすべての文書を消し、文書の ID も振り直します。元に戻せません
- **使う場面が少ない**: 静的な HTML のサイトから移すときの、ほぼ一度きりの作業です
- **ほかの方法でもできる**: 今は生成 AI に既存の HTML を渡せば、ページごとの文書名・本文を取り出したり、取り込み用の処理を書かせたりすることが簡単にできます
- **配布物を小さく保つ**: 使わないサイトにまで同梱しない

## 動作環境

- Evolution CMS JP Edition 1.3.0 以降
- PHP 7.4 以降

## 入れ方

1. `modules/importhtml/` を、サイトの `assets/modules/importhtml/` に置く
2. 次のどちらかでモジュールを作る
   - 置いたあとでインストーラー（アップデート）を流し、オプションで「Import HTML」を選ぶ
   - 管理画面の「エレメント → モジュール」で新しいモジュールを作り、名前を `Import HTML` にして、モジュールのコードに次の 1 行を貼る

     ```php
     return include MODX_BASE_PATH . 'assets/modules/importhtml/bootstrap.php';
     ```

## 使える人

| 操作 | 必要な権限 |
| --- | --- |
| 取り込み | システム設定の編集（`settings`）と、文書の作成・保存（`new_document`・`save_document`）。モジュールの実行（`exec_module`）も要る |
| 文書ツリーを空にする | 管理者（アクセス権限と Web アクセス権限の両方を管理できる人）だけ |

取り込みは、公開の権限や文書グループによる制限を確かめずに文書を作ります。そのため、編集の担当者には使わせず、サイトを移す担当者に限っています。

## 使い方

1. 取り込む HTML ファイルを、ディレクトリごとサイトの `temp/import/` にコピーする（無ければ `assets/import/` も見る）
2. モジュールを開き、左のツリーで取り込み先の親の文書をクリックする（既定はサイトの最上位）
3. 取り込む範囲（`<body>` の内側だけか、HTML ファイルまるごとか）と、リンクの変換をするかを選び、「インポート開始」を押す

取り込みの決まり:

- ファイル名（拡張子を除く）がエイリアス、`<title>` が文書名、`<meta name="description">` が説明になる
- 対象は `.html`・`.htm`・`.shtml`。文字コードは UTF-8・Shift_JIS・EUC-JP を自動で判別する
- ディレクトリはフォルダの文書になり、中の `index.html`（または `index.htm`）がその本文になる。index が無いディレクトリは、メニューに出さない空のフォルダになる
- 「HTML ファイルまるごと」では、テンプレートなし・リッチテキストなしの文書にし、`<title>` を `[*pagetitle*]` に置き換える
- 本文の中の `[*content*]` は、自分自身を呼んで循環しないよう `[ *content* ]` に崩す
- 「リンクの変換」では、取り込んだページどうしのリンク（相対・絶対とも）を `[~id~]` に置き換える。外部へのリンクはそのまま
- 「文書ツリーを空にする」（管理者だけ。最上位へ取り込むときだけ選べる）では、ルートの `index.html` をサイトの開始ページにする

## 変更履歴

### 1.0.0（2026-11-18）

- 本体の「HTMLからサイトをインポート」をモジュールとして独立させた
- 本体の機能から次の点を直した
  - 見つかったファイル数と処理時間が表示されなかった
  - 取り込み元のディレクトリが無いと、警告だけが出て何も起きなかった
  - 説明文をエスケープせずに保存していた（引用符を含むと保存に失敗する）
  - サブディレクトリの `index.htm` を二重に取り込んでいた
  - `<body>` の最後の 1 文字が欠けていた
  - リンクの変換が、親の文書の下へ取り込んだときと、サブディレクトリの中の相対リンクで効かなかった
  - まるごと取り込みのとき、既定のテンプレートの設定をその場で書き換えていた
- 取り込みをシステム設定の権限がある人に、「文書ツリーを空にする」を管理者だけに限った
